Common questions

Do I need to know how to code?

No. Just click the programs you want, then copy or download the script and run it.

What is a terminal?

The terminal is a text-based window where you type commands. On most Linux desktops you can open it by pressing Ctrl+Alt+T.

Will this work on my Linux?

Pick your distro in the generator and the script will use the right install command for it automatically.

Is it safe to run the script?

Yes. The script only installs the programs you selected using your distro's official package manager — the same tool you would use manually.
